# تغییر آیکون پوشه در ویندوز

برنامه‌ای گرافیکی برای تغییر آیکون پوشه‌ها؛ رابط آن از فونت Vazirmatn استفاده می‌کند.

## اجرای فایل EXE

فایل `dist\FolderIcon.exe` را اجرا کنید. برنامه یک فایل مستقل است و فونت‌های Vazirmatn و آیکون برنامه داخل آن بسته‌بندی شده‌اند؛ روی رایانه مقصد نیازی به نصب پایتون یا فونت Vazirmatn نیست. فایل `OFL-Vazirmatn.txt` نیز همراه خروجی برای نگهداری مجوز فونت قرار می‌گیرد.

## ساخت EXE

روی ویندوز، با پایتون و Tkinter نصب‌شده اجرا کنید:

```powershell
python -m pip install pyinstaller
.\build.ps1
```

خروجی در `dist\FolderIcon.exe` ساخته می‌شود. آیکون فایل EXE از `assets\folder_icon.ico` می‌آید.

برای اجرای نسخه پایتونی:

```powershell
python app.py
```

پوشه و فایل آیکون `.ico` را انتخاب کنید و روی «اعمال آیکون» بزنید. پنجره برنامه در مرکز صفحه باز می‌شود.

برنامه یک کپی مخفی از آیکون را در پوشه انتخاب‌شده قرار می‌دهد و `desktop.ini` را طوری تنظیم می‌کند که به آن کپی اشاره کند. برای باقی ماندن آیکون روی رایانه دیگر، کل پوشه را همراه فایل `desktop.ini` و فایل آیکون داخل آن بفرستید؛ هنگام فشرده‌سازی یا انتقال، فایل‌های مخفی را حذف نکنید.

## آزمون

```powershell
python -m unittest
```

فونت Vazirmatn با مجوز SIL Open Font License 1.1 توزیع می‌شود؛ متن مجوز در `OFL-Vazirmatn.txt` قرار دارد.
